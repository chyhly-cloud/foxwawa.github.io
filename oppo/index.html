01

Concept

两个最初命题：把门店变成城市公园，把总部变成一块被切开的璞玉。

项目从两个空间概念起步。它们先回答“人在这里如何感受品牌”，之后才进入美学研究、形式生成与材料选择。

Flagship store / Concept 01

城市公园与灵动之玉

旗舰店不再是一条被货架规定的购买路径，而是一处可以自由停留、倚靠、交流和聆听 Live 音乐的小型城市广场。OPPO 的「O」变成起伏曲线，绿色半透明材质让它像玉，也像水。

02

Inspiration sources

概念来自三组线索：人的行为、品牌符号，以及东方精神。

先把灵感拆开，才能看清之后每一个空间动作来自哪里。它不是造型拼贴，而是从场景、形态和精神三个层面逐步聚合。

01
StayLeanLiveMeet

Scene / Urban park

从购买行为，转向自由发生的生活。

城市公园没有唯一目标和固定路线。人在其中停留、相遇、观看或参与，这成为旗舰店空间关系的原型。

02
O

Form / O × Jade

从品牌字形，进入曲线、玉质与原石。

「O」提供连续曲线；玉提供透光、温润与生命力；未经雕琢的璞石提供总部的体量原型。

03
本分↔至美

Spirit / Benfen × Zhimei

从克制的本分，走向自由的至美。

本分强调尊重本质与秩序；至美追求天人合一与精神超越。两者共同构成 OPPO 美学的张力。

精神灵感继续向下追溯，成为判断设计的文化坐标。

Confucian order / Natural law

本分

从「里仁为美」出发，尊重事物本质与自然规律。它对应秩序、克制与内敛，为设计提供安静而稳定的底色。

Taoist transcendence / Unity with nature

至美

从「天地有大美而不言」出发，追求超越世俗束缚、天人合一的自由境界。美不依赖装饰，而在不可言说的意境之中。

东西方共鸣

东方的「天人合一」与海德格尔「诗意地栖居」共同指向一种状态：超越现代焦虑，重新回到宁静。

03

Research & aesthetic deduction

从灵感到设计判断：寻找 OPPO 可持续使用的美学语言。

调研不是对概念的补充说明，而是检验概念能否回到品牌内核，并形成可执行、可跨尺度转译的方法。

共同语言

现代主义

作为全球化品牌，OPPO 需要以现代主义建立与世界接轨的设计语言：清晰、理性、可跨文化理解。

现实张力

喧嚣与焦虑

现代工业文明带来效率，也带来分裂、焦虑与孤独。仅有现代主义不足以形成 OPPO 独有的精神识别。

品牌解药

东方意境

含蓄、留白与虚实相生，为现代空间提供宁静与自由，也成为 OPPO 区别于同类品牌的审美根基。

04

Aesthetic system

将品牌美学定义为：诗意美学。

它不是一种表面风格，而是一套用于判断空间、形态、材质与体验的核心准则。

根本手法

Chapter 05 / Project 01 / Flagship store

城市公园与灵动之玉

以「城市公园」打破传统零售空间的强目的性与线性货架。空间成为可以自由停留、倚靠、交互，并承载 Live 音乐与社群活动的开放场域。

核心推导

自由（功能动线）× 轻盈（视觉体量）

01

释放动线

四周墙面退让为画廊式展陈界面，中央核心区完全开敞。以离散布局取代固定路线，让使用者自行决定停留与参与方式。

02

变体品牌符号

提取 OPPO 标志中的字母「O」，将其拉伸、切分并转化为空间内起伏的陈列与交互台面。

03

消解实体重量

绿色半透明材质利用透光性消解厚重感。俯视时，台体如水波或散落的玉石，在白色空间中呈现悬浮状态。

Process evidence

先检查动线与分布，再进入空间表现。

俯视推导验证三件事：中央不被货架占满；曲面台体保持离散；人在不同节点之间可以自由选择路线。城市公园的概念先在平面关系中成立。

Result / Process verified

当动线、形态和材质都回应概念，结果才出现。

零售空间不再只服务于购买：它像一座微型城市公园，让品牌以停留、交流与参与的方式被感知。

Chapter 06 / Project 02 / Shenzhen super headquarters

璞玉之境

以未雕琢的「璞玉」为核心意象。两座深色有机塔楼如原石扎根大地，唯一的绿色高光被严格控制在顶部，形成「切开原石见翠玉」的东方意境。

宁静 / 主体 至美 / 焦点 璞玉 / 意象

Derivation route / 设计推导路径

01品牌特征宁静 / 至美

02建筑原型未雕琢的璞玉

03体量动作两块原石 → 双子塔

04对比动作黑色主体 + 绿色顶部

05城市结果东方美学的天际线坐标

核心推导

宁静（建筑主体）× 至美（视觉焦点）

01

回归本质体量

摒弃多余表皮装饰与结构堆砌，以两块未雕琢原石般的体量建立建筑的核心意象。

02

建立宁静底色

双子塔楼采用深色通体材质与绝对平滑的有机曲面，以极简而厚重的几何体块扎根城市网格。

03

控制唯一高光

将绿色渐变发光体限定于塔楼顶部。在极致宁静中制造一次虚实冲突，把超越世俗的生命力具象化。

Process evidence

先判断体量与城市关系，再强化唯一高光。

早期城市测试保留了两块原石般的完整体量，同时检查双塔比例、间距与周边天际线。绿色只停留在顶部，避免品牌色变成表皮装饰。

Result / Process verified

形体保持沉静，生命力只在顶部被看见。

总部建筑以黑色建立克制与秩序，再用顶部的翠玉光芒完成超越：品牌识别不是附加的标志，而成为城市天际线本身。

07

One system, two expressions

同一套诗意美学，在两个尺度上获得不同答案。

旗舰店通过开放与透光建立轻盈的体验；总部通过克制与对比建立宁静的城市形象。差异来自场景，统一来自品牌逻辑。

Conclusion

品牌美学不是统一所有结果的外观，而是让不同结果都能追溯到同一个清晰的内核。
