概念 CONCEPT

人間のすべては、本当に運命の枠組みの中で固定されているのか。

緻密な計算によって組み立てられたインスタレーションの構造は、壮大に定められた運命を象徴する。

両者を対比させ、同時に動かすことで、決定された運命の枠組みと、人間の主観的な行動としての自由意志との関係を探る。

着想の源

人々が「努力すれば何かを得られる」と言うのをよく耳にする。

学生時代には、一生懸命勉強しても目標を達成できない人を多く見た。

01 / PROJECT BACKGROUND

プロジェクト背景

規律・身体・自由主義をめぐる文献を読み、そこから作品の出発点となる問いを取り出した。

この前提から、規律が現れる場所を三つの尺度に分けて調べた。

左右にスライドして全体を見る

社会

リンクによる社会的規律の影響

自由意志は個人の自由を強調するが、個人の運命は規律の技術によって形づくられている。

規律の痕跡は、社会ネットワーク内の「リンク」によって生まれる。

生活

予め設定された選択と、自由の見えない枷

生活には多くの選択肢があるように見えるが、実際にはすでに設定されている。

地図、GPS、ナビゲーションは移動の選択を用意されたルートへ導く。

個体

工業文明における人間の分節化

工業文明は人間の分割を加速させ、個人を構成要素へ変えてきた。

人は社会機械に不可欠でありながら、全体としての一体性を失う。

限界

06 / DECISION / PLAN B · SELECTED

三つの尺度を、三本の軌道に凝縮する

社会、生活、個体を別々の層として構成し、それぞれの軌道上で身体部位を動かす。

LAYER 01 / 第一層 社会

社会形態

円形の軌道。記号化された社会の運行構造と、その中で動く身体部位を示す。

LAYER 02 / 第二層 生活

生活

変形した軌道。日常に組み込まれた規律の経路と、本人が自由だと考える動きを示す。

LAYER 03 / 第三層 個体

個体

軌道を持たない層。分解された身体の部品が床に散らばり、空を見上げる頭部とともに、なお自由を求める個人を示す。

DECISION / 採用理由
  1. より高度に凝縮された記号であり、解釈と伝達に適している。
  2. 制作しやすく、実現可能な目標として達成できる。
  3. 伝えたい意味を正確に伝えることができる。

問いを三つの層へ明確に整理でき、意図を失わずに制作可能な構造へ変換できるため、最終案として採用した。

07 / SIMULATION + FABRICATION

構想を、動く構造へ変換する

3DS MAXで三層の軌道、支持構造、身体部位の位置関係を検証した。

SUS304の曲げ加工と精密溶接でレールフレームを制作し、研磨して鏡面に仕上げた。
